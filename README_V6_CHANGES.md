# v6 変更内容

## 1. 墓場を一覧表示
- CPU / ローカル / オンライン対戦中に「墓場 ○枚を見る」から墓場を開けます。
- 墓場のカードを押すと拡大表示できます。

## 2. モラトリアムで引いたカードを本人に表示
- モラトリアムの魔法で山札から引いたカードを、使用者本人に確認画面で表示します。
- オンラインでは相手には引いたカードの種類・数字を送りません。
- CPUが引いたカードは人間には公開しません。

## 3. 場の表向きカードを拡大
- ベースカードはクリックで拡大できます。
- 真実の魔法などで表向きになった効果カードもクリックで拡大できます。
- 伏せカードは拡大・開示できません。

## 4. 伏せカードを置いたプレイヤーを結果で表示
- 新しく伏せた効果カードに `placedByPlayerId` を内部記録します。
- ゲーム中はこの情報を伏せカードの正体とともに公開しません。
- 最終集計でカードを開いた時に「伏せた人：○○」と表示します。

## 5. 最終集計をまとまり単位に変更
従来のようにプレイヤー合計を少しずつ加算する表示を廃止しました。

新しい流れ:
1. プレイヤーの集計開始
2. 1つ目のまとまりの伏せカードを順番に開示
3. そのまとまりだけの点数を表示
4. 次のまとまりを同様に集計
5. 最後にそのプレイヤーの全カードを表向きで一覧表示
6. `まとまり1 + まとまり2 + ... = 合計点` を表示
7. 次のプレイヤーへ
8. 全員終了後に最終順位

例:
`12 + (-4) + 7 = 15点`

## Firebase Rules
v6では新しいFirestoreコレクションは追加していないため、v5のSecurity Rulesをそのまま利用できます。
