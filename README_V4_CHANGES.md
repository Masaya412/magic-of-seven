# Online Battle v4 changes

- ローカル対戦でも、プレイヤーが行動した直後に薄黒オーバーレイで行動内容を確認するよう変更。
- 「次へ」を押すまで次プレイヤーの操作を覆うため、手番交代時の見落としを防止。
- オンライン対戦では、自分ではなく相手が行動したときだけ同じオーバーレイを表示。
- ポイントとして置いたカード・破壊・真実・モラトリアム・復活など公開情報はカードと説明を表示。
- 守護・増大・裏切りを伏せて重ねた場合は、カード裏面だけを表示し正体は公開しない。
- CPU対戦の行動確認UIも共通 `components/ActionOverlay.tsx` に整理。
- Firestore公開スナップショットに `lastActionActorId` を追加し、相手の行動か自分の行動かを判定。

Firebase Security Rulesの変更は不要です。
