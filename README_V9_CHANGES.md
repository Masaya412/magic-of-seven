# v9 changes

- CPU対戦・ローカル対戦・オンライン部屋作成時に「先攻 / 後攻 / ランダム」を選べるようにしました。
  - 2人戦: 先攻=PLAYER 1が1番手、後攻=PLAYER 1が2番手。
  - 3〜4人戦: 先攻=PLAYER 1が1番手、後攻=PLAYER 1が最後。その他の順番はランダムです。
  - ランダム=全プレイヤーの順番を抽選します。
- モラトリアムで引いたカードを `lastDrawnCard` として明示的に記録するよう変更しました。
  - 通常のモラトリアムだけでなく、復活の魔法で墓場から戻したモラトリアムを後で使った場合も、使用者本人に引いたカードを表示します。
  - オンライン対戦では引いたカードはprivate viewにのみ通知し、他プレイヤーには公開しません。

- オンライン対戦では部屋を作ったプレイヤーを基準に先攻/後攻を決め、設定はルーム情報に保存されます。
