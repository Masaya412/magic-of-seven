## CPU難易度 Lv.11〜13
従来のLv.1〜10に加えて、以下の3段階を追加。
- Lv.11 超級
- Lv.12 極級
- Lv.13 神級

Lv.11以上では、単純な優先順位ではなく、その手番で可能な候補手を評価・比較して行動する。
ポイント化、増大、裏切り、守護、破壊、真実、復活、モラトリアムを候補として比較する。
また、自分自身が過去に伏せたカードは記憶するが、相手の伏せカードの正体は参照しない。
Lv.13では判断ノイズをなくし、同じ公開情報・自分の記憶情報なら最も高く評価した行動を選ぶ。

CPUが複数いる場合は、従来どおりCPUごとに個別の難易度を設定できる。
