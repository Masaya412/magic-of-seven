# リザルト演出 v5

## 今回の修正

- フリップアニメーションは「公開する瞬間」だけ使用します。
- 一度公開した効果カードは、その後は通常の表向きカードとして固定表示します。
- 集計中に表面と裏面が混在したり、一度公開したカードが裏面に戻って見える問題を防ぎます。
- 集計順を「1枚公開 → そのカードの効果を計算 → 次の1枚」に変更しました。
- 真実の魔法でゲーム中に表向きになっていたカードも、リザルト開始時はいったん裏向きとして扱い、リザルト中に改めて公開します。
- ゆっくり / 標準 / 速い の速度変更、一時停止、スキップは維持しています。

## 主な変更ファイル

- `components/ResultRevealScreen.tsx`

## v6: 伏せカードの開示順を整理

- 得点計算の順番ではなく、実際の積み重なり順で公開します。
- `effects` の末尾（いちばん上のカード）から、下へ向かって1枚ずつ開示します。
- 全ての伏せカードを開示し終えてから得点計算へ進みます。
- 得点計算自体は従来どおり「増大 → 裏切り → 守護」で行うため、ゲームルールは変わりません。
- 真実の魔法でゲーム中に公開済みのカードも、リザルトでは裏面から順番に開示します。


## v7 変更点

伏せカードの開示順をv6と逆に変更しました。
ベースカードに近い下側の効果カードから、一番上の効果カードへ向かって1枚ずつ開示します。
