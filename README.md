# 7つの魔法

Next.js / TypeScript / Chakra UIで作成したカードゲームです。

## 起動方法

```bash
npm install
npm install firebase
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## ゲームモード

- コンピュータ対戦：1人のプレイヤー + CPU 1〜3人
- ローカル対戦：同じ端末で2〜4人

## CPUの行動

CPUは完全ランダムではなく、以下を考慮して行動します。

- ドラフト時に数字と魔法の有用性を評価
- 自分の高得点カードに増大を使用
- 自分の高得点カードに守護を使用
- 相手の高得点カードに裏切りを使用
- 脅威の高い相手カードを破壊
- 墓場の有用なカードを復活
- 相手の裏向き効果が多い場合に真実を使用
- 低い数字のモラトリアムで引き直し
- 特殊効果の価値が低い場合は高い数字をポイント化

CPUは相手の裏向きカードの正体を判断材料には使用しません。

## 実装済み

- 49枚（7種類 × 1〜7）のカード生成
- シャッフル、初期配布
- ドラフト方式で7枚の手札を確定
- 2〜4人対戦
- CPU自動ドラフト
- CPU自動ターン
- CPUの手札非公開
- ポイントとして場に配置
- 守護 / 増大 / 裏切りを裏向きで重ねる
- 破壊
- モラトリアム
- 復活
- 真実
- 墓場 / 山札
- 得点計算
- 勝者表示

## 採用したルール解釈

- 増大は1枚につき基礎点を2倍（2枚なら4倍）
- 裏切りは1枚につき -1倍（2枚なら符号が元に戻る）
- 守護は終了時に1枚につき +1点
- 破壊は上に重なったカードから取り除き、守護を破壊した時点で終了
- 守護が無ければ効果カードを全て破壊した後、基礎カードも破壊
- 真実は対象スタックに重なったカードを全公開
